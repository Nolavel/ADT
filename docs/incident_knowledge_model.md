INCIDENT KNOWLEDGE MODEL

Incident (objective fact)
- what happened (kind, victim, injury/death/theft flags)
- where / when
- source (direct / reported)

Witness observation (what the eyes got)
- observation_level (уже существующая шкала SILHOUETTE…IRIS)
- observed physical traits:
  - face (seen / not)
  - clothing / silhouette
  - equipment / weapon
  - distinctive traits
- recognition (prior encounter?)
- recording (camera / Votive image?)
- uncertainty flags

Report (what was transmitted)
- subset of the above that actually reached the registry
- status PENDING → COMMITTED / CANCELLED
- never contains a resolved actor identity

Authority / downstream
- what information is actionable
- can_identify_suspect? → NO / PARTIAL / HIGH
- consequences (dispatch area search / description match / pursue)
